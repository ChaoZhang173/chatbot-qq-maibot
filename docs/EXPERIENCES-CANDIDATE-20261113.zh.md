# 经历问答、聊天分享与日记候选（未部署）

本分支基于 2026-11-11 源码快照。2026-11-13 实施前对照线上 9 个相关文件，哈希一致。新增功能默认关闭；当前模型表达验收未通过，不能把本分支称为线上修复。

## 实现

- `experience_view.py` 直接查询实际阅读和有确认回执的活动，按时间分散选材；聊天洪峰不再挤掉早间阅读。区分今天、昨天、日历周、滚动 7 天和默认 72 小时。查询状态与覆盖范围分开，扫描结束不代表生活记录完整。
- `experience_runtime.py` 通过现有 Host 钩子把近况事实绑定到目标消息、说话者与本轮快照。本轮可信经历规则加入系统指令，外部材料保持为资料；替换本分支的 Planner 参考句，移除 Replyer 中原参考／reason 回落；正常聊天路径沿用原规则。发送前检查来源和策略，只有确认发送后才更新追问锚点。无需修改 Host 补丁。
- `shareable_experience.py` 从机器人确实参与的窗口构建分享片段，保留昵称、QQ 号、群号、说话者、原话、场景和真实回复关系。明确电话、密码、真名、地址等局部隐去。数字是否是 QQ 标识按出现位置核验，普通长技术参数不按长度删除。
- “这段别公开”排除本人当前会话的近期片段或明确引用的本人旧消息；“别把我的聊天写进日记”持久排除该说话者。引用他人请求不改变权限。没有新增完整正文副本表，也没有修改原始私聊跨会话读取权限。
- `diary_v2.py` 复用现有 Writer/Reviewer JSON 接口与草稿存储。允许私聊趣事及多段经历，来源和审核绑定策略版本；最终发送出口再检查一次，无效草稿不发布。原来的日记路径保留。
- 公开网页只接入有可信探索来源的阅读记录。QQ 账号标识不作为 B 站 @ 身份映射。Passport 身份、发布平台和发布时间不变。

分享检测是局部规则、已知保护值及模型审稿的组合；并不声称能确定识别任意语义敏感内容。追问仅在成功发送文本能可靠匹配候选标题／片段时推进；无法确认时保留不确定性，不把所有候选当成已经聊过。

## 文本资产

Gemini 原始 v1.0.0 包保持不变，本分支加入适配版本：B/C/D 为 `text_assets/` 中四个短运行时文件，A 的 24 条问法和 E 的 15 条行为样例为 `tests_experiences/fixtures/` 中的离线 JSON，另有评分说明。整套样例不会进入线上提示词。

修正了 NO_MATCH 错误否定、日历周与近 7 天混淆、单主题／25 字硬限制、虚构旧反应的正例、私聊一律禁止、昵称出现即自动 PASS，以及不兼容的自由文本审稿接口。作品角色代入与现实行动分开判断。原包 SHA-256：`7d9d17e1c660449310c48468e35265c1e27917061d4d48975f6b4e74cbd2fd7c`。

## 验证与限制

新增 28 项离线测试通过，其中包含 A 表全部 24 条问法子例，以及私聊投影、局部删改、场景归属、排除例外、跨午夜、聊天洪峰、事实撤销、失败发送、追问锚点、策略回退和最终发送检查。既有发送器使用模拟平台 API 验证；没有真实发帖。

完整回归执行 973 个测试条目，保留 53 项失败／错误条目，均在未修改基线复现，无新增失败。涉及旧学习规则预期、旧 Host 测试夹具、缺失的历史验证脚本等；完整套件不应标为全绿。详细机器可读统计见 `EXPERIENCES-VALIDATION-20261113.json`。

模型对照使用现用 DeepSeek Flash：23 条真实公开 B 站阅读记录、1 段模拟私聊、公开 v59 人格参考；本轮未提交真实私聊。冻结截止为北京时间 2026-11-12 23:59:59。回复用相同重建 Planner 参考句，经实际插件入口组装输入；不是完整 Host/QQ 端到端回放。日记另外做了同素材只换 Writer 的对照。共 27 次模型调用，103,535 个总 token。原始输入、生成结果和 HTML 对照保留在本地，不提交聊天材料到公开仓库。

观察到素材确实变丰富，最终日记保留两人的来回并通过最后一次模型审稿；早期审稿既漏检过场景错误，也误判过角色玩笑，均已留档。近况多轮对照出现无依据的旧情绪、时间错位、“没匹配”猜成“可能没看”和模板反问。将可信规则提升为本轮系统约束后，最终一轮未再将无匹配猜成否定，但时间与旧反应错误仍有出现。因此**模型表达验收未通过**，不能据单篇日记通过就建议上线。下一步应解决近况生成对证据约束的遵守，并用保留样例复验，而不是继续堆更多生活素材。

## 开关与回退

配置例见 `config/experience-features.example.json`，合并到统一核心策略中，不替换其他配置。

- `recall`：近况及追问事实接入。
- `sharing`：处理后的聊天分享片段。
- `diary`：新日记取材、Writer/Reviewer 与发布前核验。
- `web`：有可信来源的公开网页阅读接入。

关闭 `diary` 后恢复旧日记路径；已经产生的新草稿仍需新验证，不能绕到旧审核直接发布。关闭功能不删除原始证据，策略或文本资产变更使旧快照／草稿失效。未修改现用人格文件、线上配置或服务，未恢复暂停的全局风格实验。
