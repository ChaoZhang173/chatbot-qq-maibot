# 2026-11-03 身份、记忆与上下文更新

本次更新在同日 full-entry-r17 快照上合入已经部署的跨渠道回忆修复、Passport 按人绑定和 5000 字符入口修复。仍以 MaiBot 1.3.14 为上游基线，完整 Host 补丁保留原有 18 个文件的其他改动。

## 人员身份

设备使用自己的 ID 和令牌认证，由服务器分配人员身份。QQ 可选；没有 QQ 的朋友使用独立 Passport 会话。现有主人保留原会话和权限，可单独设置语音称呼。提供创建人员、分配设备、停用和可选 QQ 关联的管理员命令，默认演练，显式加 `--apply` 才写入。见 [中文管理指南](PASSPORT-IDENTITY.zh_CN.md) 和 [English guide](PASSPORT-IDENTITY.md)。

QQ 号码先记为待验证，不凭号码取得历史或权限。QQ 关联需要可信号码证据和已有私聊验证。朋友之间、朋友与主人之间的历史和工具权限隔离；设备改派不能重放前一个人的回复。身份来自设备绑定，不使用声纹识别。

## 群聊和跨渠道回忆

允许共享的已接入群聊可作为共同经历检索；QQ 和主人 Passport 会话可以直接检索已保存的语音对话，不再只依赖长期记忆摘要。语音保存状态会核对写入结果，失败可重试。普通朋友独立的 Passport 会话不因此获得主人的共享群聊或私聊内容。

`qq_group_recall_shared_enabled` 控制获准群聊共享。公开模板默认关闭，需按自己的授权范围配置。生产私有账号、群映射和设备绑定不随源码导出。

## 1800 和 5000 的含义

动态人设展示预算仍为 `persona_display_budget=1800`。插件接收的单块补充上下文正文上限从 4800 调整为 5000 字符。拼装器把附加说明前缀纳入长度预算，避免正文满足原计数但最终输出仍超限。必需规则和记录结构保留；超出入口上限的内容仍会拒绝。

此限制针对插件的补充背景正文，不代表模型总上下文窗口、回答长度或数据库容量。插件在检查之后添加自己的上下文标记，该标记不占上述正文预算。

## 更新部署

备份私有配置与状态，在准确的上游基线上应用完整 Host 补丁，并安装对应统一核心及网关版本。公开目录 `extensions/maibot_unified_core` 对应部署时的 `unified_core` 插件包；管理员指南里的模块命令使用安装后的包名。不要把示例配置覆盖到现有实例。

本次 5000 字符在线修复只需更新 `plugin.py` 和 `compact_context.py`；从旧版升级身份和回忆功能则需要同步本快照的相关插件、网关与完整 Host 补丁。已有私有绑定、聊天、记忆数据库和凭据保留在自己的服务器。

QQ 关联改变后续对话的路由，旧 Passport 原生历史仍保留，不会自动迁移到 QQ。设备在记忆同步途中改派时，已经写入的记录仍属于原人员；最终回复交付会重新核验并拒绝过期身份。

小红书运行任务保持暂停；本次发布不启用任何平台发送行为。
