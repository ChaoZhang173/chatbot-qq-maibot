# P0 实际基线与平台能力

核对日期：2026-10-24。本文记录本轮实际观察，不代表后续时刻的在线保证。

## 现有部署

- 复用现有腾讯云 Lighthouse。MaiBot 与 bilibot 均为 active/enabled；没有新建主机、数据盘或云服务。
- 服务器约 2GB 内存：核对时使用约 1017MB、可用约 949MB；约 40GB 根盘使用 7.4GB、剩余约 31GB；交换区未使用。
- 现有 unified_core 使用本机套接字，QQ 官方适配器与 B站进程分离；私聊身份绑定、统一人格和范围过滤已经存在。
- 核对到一个已验证且有会话的主人私聊绑定。没有将群 OpenID 当成私聊 OpenID。
- 对照 44 个服务器源码/清单文件，42 个与本地一致，另 2 个以服务器当前版本补齐。见 `evidence/server-parity.json`。
- 服务器仅发现 SSH 公网监听，WebUI 在回环地址；未发现现成 80/443 HTTPS 回调入口或可复用域名。
- 用户恢复连接后，已完成增量部署、服务器 API 复查、预算入账、真实主人通知与 PNG 投递。共享 SSH 会话在收尾时再次断开；最后核对的三个服务均 active/running。连接中断不能证明用户口令错误。

## 爱发电官方规范

[官方 API / Webhook 指南](https://guide.afdian.com/creator/developer) 明确支持签名查单、分页查询和订单通知。实现保留支付成功、实付金额、售卖方案、SKU/数量与留言绑定等核验；回调只入待核验队列，以官方 API 查单为依据。公开页面未给出可直接实现的回调验签、可信付款时间或完整退款接口；后台能力仍待现场确认。

已验证公开签名示例；没有宣称真实账号鉴权成功。早期主站返回521/断开而帮助页200，后续网络探测三个页面均403，浏览器也访问失败；详见 `evidence/afdian-live-probe.json`、`evidence/afdian-live-probe-final.json` 和 `evidence/browser-probe.json`。这些结果不能证明全球故障，也不能据此判断 key 无效。没有更改 API key；旧 key 已暴露在会话中，建议用户在平台恢复后轮换。

“白米饭”商品的 URL、plan_id、SKU、数量操作、留言保留情况、商品资格/说明、费率与退款入口均未现场核验。没有把它默认认定为可用于任务结算的售卖商品。

## QQ 与 B站

[腾讯官方机器人文档](https://github.com/tencent-connect/bot-docs/blob/main/docs/develop/api-v2/server-inter/message/send-receive/send.md) 顶部注明自 2025-04-21 停止主动推送；仍保留的旧额度说明不能作为可用依据。故主人主动 C2C 通知必须标为阻塞，已有私聊绑定和被动回复均不能代替该验收。用户已接受受限回复窗口方式；该方式的主人 C2C 通知已有真实回执。没有把它冒充无限期主动推送。

客户在允许的 QQ 会话中主动咨询后可走现有回复接口；确定性测试图的 C2C 文本/PNG已有真实回执；真实收费订单、群发图及窗口/次数不足后的真实补发尚待验收。包含商品链接的消息还需核对 QQ 后台 URL 配置。

B站保留既有动态功能。本轮未核实可稳定使用的自动 DM 接口，采用受保护的 owner 人工导入/回复草稿/人工送达记录；不宣称 B站自动私信接单上线。
