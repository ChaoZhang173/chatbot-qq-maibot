## Passport 完整语音入口

设备通过认证 WSS 连接语音网关。识别结果由统一核心核验设备与主人绑定后，进入现有 MaiSaka Planner、工具注册表和 Replyer；共用已有的人格、记忆和工具实现。回复仅进入当前设备的输出缓冲，不伪装成 QQ 发信。会话忙、断开、取消、重放和结果不确定有独立处理。

搜索使用操作员私有配置中的 DeepSeek 官方 Search API；网页正文使用原有的直接 HTTPS 读取器。读取会核验公开地址、限制重定向和内容大小，并保留既有内容检查。搜索服务异常不会悄悄改回 Bing。缓存按实际来源区分，避免复用旧搜索结果。

语音回合在接近截止时间时为最终回答保留时间。网络读取和内容检查受同一个剩余时间约束，避免一直重查直到设备超时。没有额外的固定单轮联网次数上限；现有日额度仍适用。慢页面或资料不足应说明未核实的内容。

## 部署

`patches/maibot-host-current.patch` 包含当前部署的全部 18 个改动或新增 Host 文件；不要再叠加旧 Host 或 Token 候选补丁。`extensions/maibot_unified_core/_manifest.json` 包含 `unified.voice` 能力声明。语音网关的依赖和启动说明见 `extensions/passport_gateway/README.md`。

`config/passport-web-search.example.json` 仅为模板。操作员在统一核心的私有状态目录创建 `web_search.json` 并填入自己的有效凭据。设备令牌、设备到主人的映射、进程 UID、Wi-Fi 和 TLS 材料须在自己的环境中独立配置。示例中的语音入口默认关闭。

本仓库提供服务端实现与设备协议/时间常量，不包含可直接刷入的固件、个人网络配置或设备证书。设备上游为 [FOLOTOY AI Passport](https://github.com/folotoy/ai-passport)。本轮未更改设备固件。
