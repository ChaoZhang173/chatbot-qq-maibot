# 经历问答、日记与群聊对象修复（2026-11-13）

已按用户授权部署经历问答、聊天分享、新日记与公开网页经历四项功能，并修复主动群聊对象归属。线上统一核心和 B 站服务恢复正常，20 个发布文件与本分支一致。人格文件、模型提供方、发布节奏沿用现行设置。配置示例默认关闭，线上仅合并四项开关，不覆盖其他配置。

## 行为变化

近况回答使用绑定到当前消息的经历材料，最终校对检查时间、谁说过什么、阅读范围、旧反应补写及无关尾问。校对失败时不发送原草稿；有可靠标题时保留一句来源可证明的回答，否则表达不确定。校对前后都检查来源与策略。已校对正文保留正常分段，关闭模拟错字，防止下游改变内容导致最终核验失败。

主动群聊不再把最后一位说话者和他的关系称呼当作默认对象。每条消息保留作者与时间；只有最近 30 分钟本人发过言、没有等待他本人回应的点名时才可选择该对象。别人的消息不能算作他的回应，升级前明确点名的记录也参与判断。旧主动发言只用于避免重复。所有群聊候选都经过语义校对，空对象的隐式点名也受检查；文字发送前和语音合成后重新核对。

聊天分享保留允许的昵称与原话，并将 QQ 引用解析成当前可见窗口的确定来源；缺失、歧义或已截断的引用不猜测对象。日记取材、审稿和最终发送核验使用同一版本和原始引用。普通私聊趣事采用已确认的局部处理政策，原始私聊检索权限保持隔离。
