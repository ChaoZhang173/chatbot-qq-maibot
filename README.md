## 通用语音终端插件（预览版）

网关现已可独立安装，通过 HTTP 接口连接自己的聊天后端；安装包仅包含语音网关，不依赖大肥鱼或 MaiBot。提供设备鉴权、语音识别/合成、连接管理及可选提醒协议。第三方后端负责自己的身份、会话、记忆和工具。

查看 [安装与接入说明](docs/PORTABLE-GATEWAY.zh_CN.md)；安装后运行 `passport-smoke` 可完成一次不调用付费服务的本机协议检查。真实设备和第三方后端仍需联调。通用预览版保持独立；当前线上源码位置见上方版本说明。

## 当前能力

- **Passport 语音入口**：接入现有 Planner、工具、Replyer、人格与记忆；官方 DeepSeek Search 搜索，直接 HTTPS 读取网页，查询接近超时时保留回答时间。见 [网关说明](extensions/passport_gateway/README.md)。
- **Passport 身份**：设备绑定独立人员身份，QQ 可选；主人与朋友权限、历史和重放结果隔离。可设置语音称呼。见 [身份管理](docs/PASSPORT-IDENTITY.zh_CN.md)。
- **跨渠道回忆**：获准共享的群聊经历和已有 Passport 对话可直接进入 QQ／主人语音回忆；语音记忆保存有状态核对和失败重试。
- **上下文长度**：补充背景入口上限 5000 字符，动态人设展示预算为 3200；拼装预算包含附加说明文字。
- **主动提醒**：支持 Passport 单次提醒的设置、修改、取消和查询，以及设备确认后播放；仅在设备开机联网且固件支持时送达。真实设备的完整提醒流程仍待验收。
- **当前运行安排**：小红书任务继续暂停。手机蓝牙配网已在当前设备上完成同一 Wi-Fi 重配和语音验收；不同 Wi-Fi、新设备及朋友的真实 QQ 关联仍待实测。

- **小红书草稿、审批与回执**：在 QQ 主人私聊审核后执行发帖、评论和回复；自然语言状态查询会查账本并可安排页面复查，符合条件的明确补发请求进入真实去重与发送流程。提交成功、本账号读回、其他账号可见和平台审核是不同状态；审核中的已提交评论不会当作未发送而重复发送，也不会仅因审核暂停全部发帖与回复。
- **人格与成长**：固定核心性格和基础行为，允许有证据地调整动态表达、兴趣和近期状态。当前 v59 参考配置强调聪明、好奇、淘气、心软和自然接话，减少固定人设表演；见 `config/persona.current.example.json`。不导出聊天证据和成长历史。
- **自主浏览与互动**：B站按独立时钟浏览，不等待 QQ 群消息。点赞、收藏、投币、关注逐项选择并记录原因，保留兴趣判断、额度、去重和平台回执校验；不保证每次浏览都会互动。
- **个人图库**：最多 100 张、100 MB，保存图片、喜好原因和检索信息，可按兴趣收藏、替换和发送。短期群聊媒体仍按会话隔离；保存到账号图库的收藏可在获准会话间使用，未授权会话不可读取。语义检索不可用时退回文字检索。
- **记忆和上下文**：保留现有学习、反思及检索能力；压缩重复上下文，短暂缓存同轮检索，表情选择只获取必要上下文。embedding 用于检索，不是不断增长的完整提示词。
- **默认安静的命令回执**：操作成功、系统命令和工具结果默认不作为群聊回复发送；用户明确要求汇报时才发送相关结果。
- **每日动态日记**：北京时间 22:30，根据当天真实记录分享想法、允许分享的聊天趣事和自主浏览见闻；可以聊一件或多件，不强制逐项点评，正文上限 800 字。发布前检查事实与隐私；@ 仅使用核验后的公开 B站身份，最多一位。
- **日夜额度**：全天可运行，普通互动使用日夜额度，夜间约为日间四分之一；当前直播弹幕另按自然日计算，主动探访频率仍按夜间额度控制。

## 验证

Passport 检查另见 `python scripts/run_passport_checks.py`；先安装 `extensions/passport_gateway/requirements.txt`。本次实际运行范围与历史测试分开记录在快照说明中。

使用 Python 3.12，在独立环境安装 `requirements-dev.txt`，然后执行：

```sh
python scripts/run_current_tests.py
```

这是使用模拟平台与模型的离线测试，不会发布动态或消耗互动额度。Host 基线补丁测试默认跳过；如有合法获取的 MaiBot 1.3.14 完整源码，可设置 `MAIBOT_SOURCE_ROOT` 指向其 `src` 后运行。部分历史测试依赖旧部署工具、上游 `bili_login` 或桥接模块，因此当前入口只运行自包含的维护套件；不将全部历史测试宣称为已验证。

## 部署与隐私
