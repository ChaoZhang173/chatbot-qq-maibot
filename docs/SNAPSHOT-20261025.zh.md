本次将自主互动、上下文精简、个人图库、安静命令回执、日夜额度及每日动态日记合并到公开维护仓库。54 个扩展源码／清单直接与运行实例核对；源码哈希见 `source-manifest-20261025.json`。没有迁移或删除线上聊天、学习记录、记忆和图片。

## 行为与验证边界

B站浏览由自身的运行循环驱动。每个候选视频分别决定点赞、收藏、投币和关注，并保存接受或拒绝的原因。评论额度用尽不阻止独立的浏览互动；所有写操作仍遵守身份绑定、单写入者、预算、去重和结果核验。

图库同时限制 100 张及 100,000,000 字节，保留喜好标签、来源及权限范围。保存后的图片独立于短期媒体缓存；保存失败不删旧图。每天最多新增／替换 5 张，后台挑选最多 4 轮、每轮最多 3 个候选。群聊来源不越过原会话边界，来自公开网页的图片采用公开范围；上传仓库不包含任何真实图片。

上下文由当前人格和相关检索组成，同轮结果短期复用；表情选择只读取必要内容。长期记忆、学习、反思以及图库语义索引继续保留。离线测试验证边界、缓存与恢复行为，不把提示词长度变化直接当成长期实测费用下降。

日记默认北京时间 22:30 尝试。输入来自当日公开 B站记录、确认成功的活动及大肥鱼确实参与的群聊片段。群聊先过滤敏感内容、移除姓名与标识，再形成最多两段匿名经历摘要；写作模型不读取原始群聊。审校核对脱敏原片段与来源，要求有真实感受和具体经历，禁止编造线下体验或观看细节。公开 B站昵称和 @ 必须有身份来源及发送前核验，最多一位；不把 QQ 名称推测映射成 B站用户。

日记按本地日期去重，预留一次动态和最多六次模型调用（每次尝试三次）；生成失败最多两次、相隔至少十五分钟。未知发送结果不自动重发，漏过的旧日期不补发。加长正文只开放给严格匹配日期的日记动作，普通动态／评论限制保持不变。本次已验证真实记录预览与模拟发送路径；本次发布不宣称新的定时日记已公开发送。

## 配置与升级

`config/bilibili.current.example.json` 保存非敏感开关、日夜周期、基础限额及日记时间。为避免直接复制触发活动，模板 `paused=true`，身份与来源列表为空。限时活动 boost 依赖有效开始／结束时间和完整结构，因此没有导出本实例的活动时限；它不是已启用临时额度的精确副本。`quota_reset_at` 也不复制。`config/unified.current.example.json` 保留学习能力开关，群／主人映射必须私下配置。

当前 `extensions/maibot_unified_core` 和 `extensions/qq_official_adapter` 已包含收单桥接代码。`extensions/paidtasks/integration` 及其构建器只适用于 2026-10-24 收单前基线；不要再次对当前源码应用。付款服务原有生产配置仍保持私密；本次不改变接单状态。

Host 更新使用 `patches/maibot-host-current.patch`，目标文件相对于上游 `src`。先核对配套 `maibot-host-current.hashes.json`：上游匹配才能应用，部署后匹配则无需重复操作；其他哈希必须人工审查差异。将统一核心 `host_adapter.py` 安装到 Host 对应能力目录。现有 `host_patch.py` 对已安装但版本不同的 adapter 会拒绝覆盖；升级前应明确核对旧文件并保留私密备份，不绕过检查。

新功能测试中的 Host 补丁基线用例需要完整上游源码，其余测试入口不依赖生产配置或连接。历史 `tests_phase25` 中一部分测试依赖未随本仓库提供的旧部署工具；历史 `test_bridge.py` 和 `test_login_ui.py` 依赖上游桥接及登录模块。当前统一入口明确列出可复现套件。
