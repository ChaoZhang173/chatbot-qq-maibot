# 大肥鱼：QQ／B站聊天机器人部署扩展

2026-10-25 当前部署版本的脱敏源码快照。基于 MaiBot 1.3.14，保存统一核心、QQ 官方适配器、B站执行器和必要 Host 补丁；不包含完整上游程序或生产运行数据。

## 当前能力

- **自主浏览与互动**：B站按独立时钟浏览，不等待 QQ 群消息。点赞、收藏、投币、关注逐项选择并记录原因，保留兴趣判断、额度、去重和平台回执校验；不保证每次浏览都会互动。
- **个人图库**：最多 100 张、100 MB，保存图片、喜好原因和检索信息，可按兴趣收藏、替换和发送。来自群聊的图片保留会话边界，语义检索不可用时退回文字检索。
- **记忆和上下文**：保留现有学习、反思及检索能力；压缩重复上下文，短暂缓存同轮检索，表情选择只获取必要上下文。embedding 用于检索，不是不断增长的完整提示词。
- **默认安静的命令回执**：操作成功、系统命令和工具结果默认不作为群聊回复发送；用户明确要求汇报时才发送相关结果。
- **每日动态日记**：北京时间 22:30，根据当天真实记录写感受、匿名群友互动和自主浏览见闻，目标约 400–600 字、正文上限 800 字。发布前检查事实与隐私；@ 仅使用核验后的公开 B站身份，最多一位。
- **日夜额度**：全天可运行，日间与夜间分别计数；夜间额度约为日间四分之一，跨午夜和重启不清零。

## 目录

- `extensions/maibot_unified_core`、`extensions/phase2`、`extensions/qq_official_adapter`：当前完整扩展源码，已合并既有收单接口，不能重复套用旧收单补丁。
- `extensions/paidtasks`：保留爱发电小任务模块和历史验收说明；接单关闭、真实支付验收未完成。
- `extensions/tests_dafeiyu`：当前功能回归；`tests`：配置与公开文件安全检查。
- `patches/maibot-host-current.patch`：相对 MaiBot 1.3.14 的 Host 改动；配套哈希记录用于核对基线。
- `config/*.current.example.json`：脱敏运行配置示例。B站模板保持暂停，账号和群映射为空或占位符；临时活动期限、一次性额度重置和私人来源列表未导出。
- `docs`：当前快照说明、源码校验清单及历史运维文档。

## 验证

使用 Python 3.12，在独立环境安装 `requirements-dev.txt`，然后执行：

```sh
python scripts/run_current_tests.py
```

这是使用模拟平台与模型的离线测试，不会发布动态或消耗互动额度。Host 基线补丁测试默认跳过；如有合法获取的 MaiBot 1.3.14 完整源码，可设置 `MAIBOT_SOURCE_ROOT` 指向其 `src` 后运行。部分历史测试依赖旧部署工具、上游 `bili_login` 或桥接模块，因此当前入口只运行自包含的维护套件；不将全部历史测试宣称为已验证。

## 部署与隐私

API key、密码、Cookie、访问令牌、SSH 公私钥、证书、服务器地址、真实账号／群／主人标识、原始聊天、日记预览、图库图片、数据库和私有备份不在本次上传内容中。服务器现有记忆与图库留在服务器；仓库保存相关功能代码。上传检查会同时扫描公钥、私钥和配置中的非空凭据，不能代替人工审查。

这是维护已有实例的增量仓库。升级前应备份私有配置和状态，核对源码哈希、插件注册与上游版本，只替换对应文件。Host 需要注册统一记忆接口、安装 `host_adapter.py` 为 `src/plugin_runtime/capabilities/unified_memory.py`，并支持 `request_kind`；仅复制插件不能从零启动。具体见 [当前快照与部署边界](docs/SNAPSHOT-20261025.zh.md)。

旧人格配置、历史增量脚本及收单构建器是历史资料，不能直接覆盖当前实例。参见 [上游来源与许可证](UPSTREAM.md)、[收单报告](extensions/paidtasks/REPORT.zh.md) 和 [历史运维说明](docs/OPERATIONS.zh.md)。
